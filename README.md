# Aplicação para gerenciamento de prontuários veterinários utilizando FastAPI

## Integrantes:
- Ithawana de Oliveira Cunha  
- Mariana Kessia de Lavor Assuncao
- Moacir Silva Abreu

## Tema
Prontuários Veterinários

## Descrição:
O presente trabalho tem como objetivo o desenvolvimento de um Cofre Digital de Prontuários Veterinários, sistema que permitirá armazenar, gerenciar e proteger documentos digitais de atendimentos clínicos de animais (exames, receitas, laudos e demais registros em PDF ou imagem).

O sistema será desenvolvido em Python com FastAPI, e permitirá o upload de documentos associados a metadados do atendimento(nome do animal, espécie, tutor...), além de possibilitar consulta, filtragem, atualização, verificação de integridade, exportação e backup dos dados, utilizando persistência em JSON, CSV, YAML e arquivos binários.
